# Machine Learning & Data Science Internship

## About This Repository
This repository contains practical projects completed as part of my Machine Learning and Data Science Internship. The projects focus on data analysis, data preparation, machine learning model development and evaluation.

## Projects

### 1. Multi Class  Classification
- Explored and analysed the Iris dataset.
- Performed exploratory data analysis (EDA) using visualisations.
- Built and compared Decision Tree, Logistic Regression and Random Forest models.
- Evaluated model performance using accuracy, precision, recall, F1-score, confusion matrices and ROC-AUC.
- Used cross-validation and feature importance to support model selection.

### 2. Customer Churn Prediction
- Analysed customer data to understand churn patterns.
- Cleaned and prepared data for machine learning.
- Explored class imbalance.
- Built classification models, including Logistic Regression and Random Forest.
- Evaluated model performance using accuracy, precision, recall, F1-score and ROC-AUC.
- Explored techniques to improve the identification of customers likely to churn.
